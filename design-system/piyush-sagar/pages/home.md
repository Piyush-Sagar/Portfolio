# Portfolio implementation direction

This page refines the ui-ux-pro-max personal portfolio recommendation in MASTER.md.

- Use an editorial, asymmetric composition with generous whitespace and restrained borders.
- Light default: warm paper (#f8f7f3), ink (#242621), cobalt (#3157d5). Support a separately tuned dark theme with the same hierarchy.
- Keep Plus Jakarta Sans for readable body text and expressive bold headings, Geist Mono for small section labels and technical content. Handwritten notes use an italic serif fallback.
- Follow the narrative: introduction → selected work → about → toolkit → education → contact.
- Keep the two existing projects, original profile destinations, academic results, portrait, and résumé. Project graphics are decorative illustrations, not actual product screenshots.
- Use semantic HTML, Phosphor SVG icons, 44px controls, visible focus, a skip link, native anchor navigation, an accessible mobile disclosure, and reduced-motion support.
- Prefer modest color and transform feedback; avoid scroll hijacking, continuous floating animations, and hiding content until JavaScript runs.
- Use responsive layouts at 600px, 900px, and 1100px. Check 375px, 768px, 1024px, and 1440px, both themes, and keyboard interactions.
- Do not use subjective skill percentages or invented performance metrics.
